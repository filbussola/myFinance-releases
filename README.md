# myFinance · versioni

Qui ci sono solo le versioni pubblicate di **myFinance**, l'app di finanza
personale: l'installer per Windows, l'APK per Android e le note di ogni
versione. Il codice sta in un repository privato.

## Scaricare l'ultima versione

- **Windows**: [myFinance-setup.exe](https://github.com/filbussola/myFinance-releases/releases/latest/download/myFinance-setup.exe).
  Si installa per il tuo utente in `%LOCALAPPDATA%\Programs\myFinance`, senza
  permessi di amministratore, con la voce nel menu Start.
- **Android**: [myFinance.apk](https://github.com/filbussola/myFinance-releases/releases/latest/download/myFinance.apk).
  Al primo download Android chiede di consentire l'installazione di app da
  questa fonte.

Questi due link scaricano sempre l'ultima versione.

## Aggiornare

Non serve tornare qui: all'apertura l'app controlla se c'è una versione nuova
e la propone con le novità. Su Windows si installa da sola e l'app si riapre;
su Android scarica l'APK e apre l'installazione.

## Novità

Le note di ogni versione sono nelle
[Release](https://github.com/filbussola/myFinance-releases/releases) e, dentro
l'app, in Impostazioni › Versione e aggiornamenti › Novità.
